# Teacher Nelly's Young Learners Academy — Android App

This Android project wraps the deployed academy website in a secure HTTPS WebView.

## Build on GitHub

1. Create a GitHub repository.
2. Upload the contents of this `android-app` folder to the repository root.
3. Add the GitHub Actions workflow from `.github/workflows/build-apk.yml`.
4. Open **Actions → Build Android APK → Run workflow**.
5. When it finishes, download the `teacher-nelly-academy-debug-apk` artifact.

The app icon is generated from the supplied Teacher Nelly academy artwork.
